A tese

Foco.

Não é o volume do que você faz. É a repetição no mesmo lugar, no código e na comunidade, até associarem seu nome a alguma coisa.

Uma frase. A evidência vem na conversa.
Onde o foco acontece

Código é metade. Comunidade é a outra.

No código

  • Issues e triagem
  • Review e documentação
  • Pull requests

Na comunidade

  • Meetup todo mês, o mesmo
  • CFP, palestra, evento
  • Mentoria e organização

Quem só escreve código é descoberto por acaso. Quem aparece é lembrado.

O slide que equilibra a talk. Contar rápido uma oportunidade que veio de evento, não de PR. Evento é onde a indicação nasce.
